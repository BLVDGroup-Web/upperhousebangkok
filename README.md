# Upper House Drinks Menu

Drinks menu page for Upper House, Sukhumvit 24, Bangkok. Same format as the Baccarat menu (baccarat.menu.24blvd.com).

- `index.html` — the page (Lenis smooth scroll from jsDelivr, everything else local)
- `img/` — bottle, cocktail, rule-icon, Red Bull and logo images
- `Upper-House-Drinks-Menu.pdf` — A4 landscape print version

Served with GitHub Pages from the `main` branch root.
